# 0001 Modular monolith on Spring Boot

The assignment is one service, one demo, one GitHub repo. A modular monolith (packages `identity`, `dealership`, `customer`, `vehicle`, `appointment`, `reminder`, `notification`) keeps boundaries explicit without network hops. Microservices, Gateway, and Kafka would add failure modes the 5-minute video cannot defend. Modules may become processes later; v1 is one JVM + Compose dependencies.
