# Docker (TRD)

Why the split and the caps: [../decision/docker-runtime.md](../decision/docker-runtime.md), [../decision/scale.md](../decision/scale.md). Docker Desktop here is 16 CPU / 7.57 GiB; the numbers below are a partition of **that**, not a generic production SKU.

- `Dockerfile` (repo root): multi-stage Maven build → JRE 21 image, non-root, `java -jar`, `-XX:MaxRAMPercentage=50` so heap follows the container (no guessed `-Xmx`). One image, the application.
- `docker/docker-compose.deps.yml`: Postgres 16, RabbitMQ, Redis. Named volumes. **No app.** Creds from root `.env` (`SPRING_DATASOURCE_*`, `POSTGRES_DB`, `SPRING_RABBITMQ_*`) via `docker compose --env-file .env`. Postgres 2 CPU / 2 GiB (`shared_buffers=256MB`, `shm_size=256m`) because SKIP LOCKED lives there. RabbitMQ 1 / 1 GiB. Redis 0.5 / 256 MiB (Bucket4j only). Host Postgres is `5432` when the local Windows service is stopped. Use this with `./mvnw spring-boot:run` (`make deps` / `make run`).
- `docker/docker-compose.app.yml`: **app container only** (build context = repo root `Dockerfile`). Mounts `../logs` for `notify: false`. App **4 CPU / 3.5 GiB**. Same `.env` as `make run`; Compose **overrides** only the broker hosts to service names (`postgres` / `redis` / `rabbitmq`) and builds the JDBC URL from `POSTGRES_DB`. No second `COMPOSE_*` URL set. `make app` merges deps + this file.
- `docker-compose.yml` (repo root): **main** file. Includes `docker/docker-compose.deps.yml` and `docker/docker-compose.app.yml`. `docker compose up --build` / `make up`. Deploy later on EC2 with this file. SMTP is **Brevo** from `.env`; no Mailhog.

Production public host: `https://dealership.greatnerve.com` (OpenAPI server). CORS allows **all origins** (`APP_CORS_ORIGINS=*`). Do not set `SPRING_PROFILES_ACTIVE=dev` on the production host — that profile seeds demo users (Flyway V900) and defaults the one-Confirmed-per-Vehicle cap off. `make run` defaults to `dev` for local Maven. Production must set `APP_JWT_SECRET` to a unique value (≥ 32 bytes), not the committed default.
